# 逐页讲稿与演讲者备注

以最新PPT和既有讲稿为底稿。沿用原来的汇报框架，在每页补上表达目的、图表解读、结果评价与必要的页间衔接。开场直接进入主题，以自然的陈述句为主。每页写成一段，段内无空行。页标题只用于定位。

| 页面 | 口播重点 |
| --- | --- |
| 文章题名页 | 先用一段话交代研究目的、方法、实验对象或任务以及主要结果，再进入正文。 |
| 背景 | 讲清实际问题、现有方法在哪个环节受限，以及研究为何从这里入手。 |
| 方法 | 指出图中各部分的作用，按样本、信号或数据的流向解释它们怎样衔接。 |
| 结果 | 交代实验目的，先提示看哪组或哪条曲线，再讲实际观察和证据边界。只读支撑结论的数字。 |
| 讨论 | 收束作者做成的工作、局限和对自己课题的启发。把已验证结果和拟尝试路线分别说清。 |
| 课题计划 | 交代每一步为何开展、做完能判断什么，以及如何支撑下一步。 |

转场可以从上一页尚未解决的环节切入。例如，说明装置能够并行分滴后，再用液滴体积分布解释为什么定量需要各路独立的体积参数。避免为每页机械添加一个设问。

## 结果与原文核对

- 设计图说明预设关系，结果图说明观察到的表现。例如，探针配置表展示位点、探针和通道的对应关系，匹配与非匹配的实测结果用于评价区分能力。
- 按实际加样条件描述多重验证。区分多套引物共存、逐种加入模板与多种模板同时检出。
- 核对数值单位、检出限定义和验证方式。空白背景估算的检出限与低浓度重复验证分别说明。
- 把读出和反应机制分开。例如，特异性探针未读到空白信号支持所测条件下读出背景较低。判断反应内是否形成非特异性产物需要独立证据。
- 方法细节回到正文和补充材料核对，尤其是步骤的顺序、片内外位置，以及设计时使用的编码与实验真正采用的读出方式。

## 写回PPT

1. 先给逐页文字稿供审阅，以指定PPT实际页序定位，备用页按需求保留讲稿。
2. 用户要求写回后，先建立可恢复的备份，再更新指定原文件的演讲者备注正文。出处按幻灯片引用规则处理。
3. 重新读取备注，核对页数、顺序、文本完整性和段落格式。检查备注以外的页面内容与版式。
